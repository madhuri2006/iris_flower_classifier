# iris_flower_classifier
The main aim of this project is to classify iris flowers into three different species — Setosa, Versicolor, and Virginica — based on the measurements of their sepals and petals (length and width).

The Iris dataset contains 150 samples in total, with 50 samples from each species. Each sample includes four features:

Sepal Length

Sepal Width

Petal Length

Petal Width

Using these measurements, we build a machine learning model that can learn patterns from the given data and correctly identify the species of a flower.

The ultimate objective is not just to classify the flowers in the dataset, but to create a model that can accurately predict the species of new, unseen flowers. In other words, the goal is to develop a model with good generalization ability.
